# Dev Ops

GitHub actions creates WebGL builds and deploys them to GitHub pages. For details, [this link explains how CI was enabled](https://game.ci/docs/github/activation/#personal-license). To generate `C:/ProgramData/Unity/Unity_lic.ulf`, may need to re-sign into Unity Hub and click `Add license`/personal [even if you already have one](https://github.com/game-ci/documentation/issues/469#issuecomment-2573733797).
